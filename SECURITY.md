# Security Policy

## Reporting a vulnerability
Do not open a public issue. Use GitHub private vulnerability reporting on this repository (Security tab, "Report a vulnerability"). Include affected version, reproduction steps and impact.

## Scope
Template source, workflows, Bicep and the `golden` CLI. Products generated from this template own their own security posture.

## Handling
Reports are acknowledged, triaged by severity and fixed on a private branch before disclosure. Never include secrets in reports.
